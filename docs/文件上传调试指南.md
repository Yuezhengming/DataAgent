# 文件上传调试指南

## 问题：TypeError: Cannot read properties of undefined (reading 'fileName')

这个错误表示前端代码尝试访问 `undefined` 对象的 `fileName` 属性。

---

## 🔍 问题分析

### 可能的原因

1. **后端返回数据结构不符合预期**
2. **网络请求失败但没有正确处理**
3. **响应数据被 Axios 拦截器修改**
4. **后端返回了错误响应**

---

## ✅ 已修复的问题

### 1. 配置文件大小限制

**问题：** HTTP 413 错误（请求实体过大）

**解决：** 已将 `application.yml` 中的文件大小限制从 10MB 提升到 100MB

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 100MB
      max-request-size: 100MB
```

### 2. 前端数据访问错误

**问题：** 前端代码访问 `response.data.fileName`，但后端返回的是 `response.originalFilename`

**解决：** 已修复前端代码，正确访问后端返回的字段

## 🔧 常见问题和解决方案

### 问题 1: 413 Request Entity Too Large

**原因：** 文件太大，超过服务器限制

**解决方案：**

1. 确认已修改 `application.yml`（已完成）
2. 重启 Spring Boot 应用
3. 如果使用 Nginx，添加配置：
   ```nginx
   client_max_body_size 100M;
   ```

### 问题 2: 404 Not Found

**原因：** 接口路径不正确或应用未启动

**解决方案：**

1. 确认应用已启动：`http://localhost:8065`
2. 检查接口路径：`/api/upload/dataset`
3. 查看后端日志

### 问题 3: 500 Internal Server Error

**原因：** 后端代码执行出错

**解决方案：**

1. 查看后端日志：
   ```bash
   tail -f logs/spring.log
   ```
2. 检查错误堆栈信息
3. 常见原因：
   - 文件存储目录不存在
   - 文件解析失败
   - 数据库连接失败

### 问题 4: CORS 错误

**原因：** 跨域请求被阻止

**解决方案：**

检查是否配置了 CORS。如果前后端分离部署，需要添加 CORS 配置。

### 问题 5: TypeError: Cannot read properties of undefined

**原因：** 前端代码访问了不存在的属性

**解决方案：**

1. 检查浏览器控制台的 `Upload response:` 日志
2. 确认响应数据结构
3. 已在代码中添加了安全访问：
   ```javascript
   fileName: response.originalFilename || fileName
   fileType: response.fileType || ''
   filePath: response.filePath || ''
   ```

## 🚀 快速解决方案

如果遇到 `TypeError: Cannot read properties of undefined (reading 'fileName')` 错误：

### 方案 1: 清除缓存并重启

```bash
# 1. 停止前后端应用（Ctrl+C）

# 2. 清除前端缓存
cd spring-ai-alibaba-data-agent-frontend
rm -rf node_modules/.vite
npm run dev

# 3. 重启后端
cd spring-ai-alibaba-data-agent-management
mvn clean spring-boot:run
```

### 方案 2: 检查响应数据

在浏览器控制台查看 `Upload response:` 日志，确认：
- `response.success` 是否为 `true`
- `response.originalFilename` 是否存在
- `response.filePath` 是否存在
- `response.columns` 是否是数组

### 方案 3: 使用 curl 测试

```bash
curl -X POST http://localhost:8065/api/upload/dataset \
  -F "file=@test_data.csv" \
  -H "Accept: application/json"
```

查看返回的 JSON 是否正确。
