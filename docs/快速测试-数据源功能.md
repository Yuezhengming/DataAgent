# 快速测试 - 数据源功能

## 🎯 测试目标

验证以下功能是否正常工作：

2. ✅ 文件数据源创建

## 🚀 准备工作

### 1. 启动应用

**后端：**
```bash
cd spring-ai-alibaba-data-agent-management
mvn spring-boot:run
```

**前端：**
```bash
cd spring-ai-alibaba-data-agent-frontend
npm run dev
```

使用项目根目录的 `test_data.csv`，或创建自己的测试文件：

## 📝 测试步骤

### 测试 1: 创建智能体

1. 访问 `http://localhost:5173`（或前端配置的端口）
2. 点击"创建智能体"
3. 填写信息：
   - 名称：`测试智能体`
   - 描述：`用于测试数据源功能`
4. 点击"创建"
5. **预期结果**：智能体创建成功，进入智能体详情页

---

### 测试 2: 上传 CSV 文件数据源

1. 在智能体详情页，点击"数据源配置"标签
2. 点击"添加数据源"按钮
3. 选择"上传文件数据源"标签（应该是默认选中的）
4. 拖拽或点击上传 `test_data.csv`
5. **预期结果**：
   - ✅ 显示上传进度
   - ✅ 上传成功后显示文件预览
   - ✅ 显示文件基本信息（文件名、类型、列数、行数）
   - ✅ 显示列信息表格（列名、数据类型）
   - ✅ 显示数据预览表格（前5行）
   - ✅ 自动填充数据源名称（文件名去掉扩展名）

6. 填写数据源信息：
   - 名称：`销售数据`（或保持自动填充的名称）
   - 描述：`2024年销售数据`

7. 点击"创建文件数据源"
8. **预期结果**：
   - ✅ 显示"文件数据源创建成功！"
   - ✅ 显示"数据源已添加到当前智能体"
   - ✅ 对话框关闭
   - ✅ 数据源列表中出现新创建的数据源
   - ✅ 数据源状态为"启用"（绿色标签）

---

### 测试 3: 上传 Excel 文件数据源

1. 再次点击"添加数据源"按钮
2. 选择"上传文件数据源"标签
3. 上传一个 Excel 文件（.xlsx 或 .xls）
4. **预期结果**：
   - ✅ 文件上传成功
   - ✅ 显示文件预览
   - ✅ 列信息和数据预览正确显示

5. 填写数据源名称：`员工数据`
6. 点击"创建文件数据源"
7. **预期结果**：
   - ✅ 数据源创建成功
   - ✅ 数据源列表中有两个数据源
   - ✅ **重要**：第一个数据源（销售数据）状态变为"禁用"
   - ✅ 第二个数据源（员工数据）状态为"启用"

### 测试 4: 启用/禁用数据源

#### 4.1 禁用当前启用的数据源

1. 找到状态为"启用"的数据源（员工数据）
2. 点击"禁用"按钮
3. **预期结果**：
   - ✅ 不弹出确认对话框
   - ✅ 显示"数据源已禁用"
   - ✅ 数据源状态变为"禁用"（灰色标签）
   - ✅ 按钮文字变为"启用"

#### 4.2 启用数据源（无其他启用的数据源）

1. 点击刚才禁用的数据源的"启用"按钮
2. **预期结果**：
   - ✅ 不弹出确认对话框
   - ✅ 显示"数据源已启用，其他数据源已自动禁用"
   - ✅ 数据源状态变为"启用"
   - ✅ 按钮文字变为"禁用"

#### 4.3 启用数据源（有其他启用的数据源）

1. 现在"员工数据"是启用状态
2. 点击"销售数据"的"启用"按钮
3. **预期结果**：
   - ✅ **弹出确认对话框**
   - ✅ 对话框内容："启用此数据源将自动禁用其他已启用的数据源，是否继续？"
   - ✅ 有"确定"和"取消"按钮

4. 点击"取消"
5. **预期结果**：
   - ✅ 对话框关闭
   - ✅ 数据源状态不变
   - ✅ "员工数据"仍然是启用状态

6. 再次点击"销售数据"的"启用"按钮
7. 这次点击"确定"
8. **预期结果**：
   - ✅ 显示"数据源已启用，其他数据源已自动禁用"
   - ✅ "销售数据"状态变为"启用"
   - ✅ "员工数据"状态变为"禁用"

## 🐛 常见问题排查

### 问题 1: 文件上传失败 - 413 错误

**原因：** 文件太大

**解决：**
1. 确认 `application.yml` 中配置了 `max-file-size: 100MB`
2. 重启后端应用
3. 如果使用 Nginx，配置 `client_max_body_size 100M;`

### 问题 2: 文件上传失败 - TypeError

**原因：** 前端代码访问了不存在的属性

**解决：**
1. 打开浏览器开发者工具（F12）
2. 查看 Console 标签的错误信息
3. 查看 Network 标签的响应数据
4. 参考 `docs/文件上传调试指南.md`

### 问题 3: 启用数据源失败

**原因：** 可能是网络问题或后端错误

**解决：**
1. 打开浏览器开发者工具
2. 查看 Network 标签的请求状态
3. 查看后端日志：
   ```bash
   tail -f logs/spring.log
   ```
4. 确认错误信息

### 问题 4: 数据源状态不同步

**原因：** 前端缓存或网络延迟

**解决：**
1. 刷新页面（F5）
2. 强制刷新（Ctrl+Shift+R）
3. 清除浏览器缓存

### 问题 5: 文件预览显示空白

**原因：** 文件格式不正确或编码问题

**解决：**
1. 确认文件格式：
   - CSV 文件应该是 UTF-8 编码
   - Excel 文件应该是 .xlsx 或 .xls 格式
2. 检查文件是否有表头
3. 检查文件是否为空
