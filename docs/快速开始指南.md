本指南将帮助您快速搭建和运行 DataAgent 项目。

## 🚀 快速启动（5分钟）

### 步骤 1: 克隆项目

```bash
git clone https://github.com/alibaba/spring-ai-alibaba.git
cd spring-ai-alibaba/community/data-agent/DataAgent
```

### 步骤 2: 准备数据库

**方式 1: 使用 Docker（推荐）**

```bash
docker run -d \
  --name dataagent-mysql \
  -p 3307:3306 \
  -e MYSQL_ROOT_PASSWORD=root \
  -e MYSQL_DATABASE=data_agent \
  mysql:8.0
```

**方式 2: 使用本地 MySQL**

```sql
CREATE DATABASE data_agent CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 步骤 3: 配置环境变量

创建 `.env` 文件或设置环境变量：

```bash
# 阿里云 DashScope API Key（必需）
export AI_DASHSCOPE_API_KEY=your-dashscope-api-key

# 数据库连接（可选，默认值如下）
export DATA_AGENT_DATASOURCE_URL=jdbc:mysql://127.0.0.1:3307/data_agent?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai
export DATA_AGENT_DATASOURCE_USERNAME=root
export DATA_AGENT_DATASOURCE_PASSWORD=root
```

**获取 DashScope API Key**:
1. 访问 [阿里云 DashScope 控制台](https://dashscope.console.aliyun.com/)
2. 注册/登录账号
3. 创建 API Key

### 步骤 4: 启动后端

```bash
cd spring-ai-alibaba-data-agent-management
mvn clean spring-boot:run
```

**启动成功标志**:
```
Started DataAgentApplication in 15.234 seconds
```

后端服务运行在: `http://localhost:8065`

### 步骤 5: 启动前端

```bash
cd spring-ai-alibaba-data-agent-frontend
npm install
npm run dev
```

**启动成功标志**:
```
VITE v5.x.x  ready in xxx ms

➜  Local:   http://localhost:3000/
```

前端应用运行在: `http://localhost:3000`

## 🎯 第一次使用

### 1. 创建智能体

访问 `http://localhost:3000`，点击"创建智能体"：

**基本信息**:
- 名称: `销售数据分析助手`
- 描述: `专注于销售数据分析`
- 分类: `数据分析`
- 状态: `已发布`

### 2. 配置数据源

**创建数据源**:
1. 进入"数据源管理"
2. 点击"添加数据源"
3. 填写连接信息：
   - 名称: `测试数据库`
   - 类型: `MySQL`
   - 主机: `127.0.0.1`
   - 端口: `3307`
   - 数据库名: `product_db`（示例数据库）
   - 用户名: `root`
   - 密码: `root`
4. 点击"测试连接"
5. 保存

**绑定数据源到智能体**:
1. 进入智能体详情页
2. 选择"数据源"标签
3. 点击"绑定数据源"
4. 选择刚创建的数据源
5. 点击"初始化 Schema"
6. 选择要分析的表（如 `users`, `orders`, `products`）
7. 确认初始化

### 3. 开始对话

1. 点击智能体卡片上的"运行"按钮
2. 在输入框输入自然语言查询：
   ```
   查询最近一周销售额最高的前10个产品
   ```
3. 观察 Graph 工作流的执行过程
4. 查看生成的 SQL 和分析结果

## 🔧 配置说明

### application.yml 核心配置

**位置**: `spring-ai-alibaba-data-agent-management/src/main/resources/application.yml`

```yaml
spring:
  # DataAgent 业务数据库（存储智能体、会话等）
  datasource:
    url: ${DATA_AGENT_DATASOURCE_URL}
    username: ${DATA_AGENT_DATASOURCE_USERNAME}
    password: ${DATA_AGENT_DATASOURCE_PASSWORD}
  
  ai:
    # 向量数据库类型
    vectorstore:
      type: simple  # 开发环境使用内存向量库
      # type: milvus  # 生产环境使用 Milvus
      # type: elasticsearch  # 使用 Elasticsearch 混合检索
    
    # 阿里云 DashScope 配置
    dashscope:
      api-key: ${AI_DASHSCOPE_API_KEY}
      chat:
        options:
          model: qwen-plus  # 对话模型
      embedding:
        options:
          model: text-embedding-v4  # 嵌入模型
    
    alibaba:
      nl2sql:
        llm-service-type: stream  # 流式输出
        code-executor:
          code-pool-executor: local  # Python 执行环境
          # code-pool-executor: docker  # 生产环境推荐
        file:
          type: local  # 文件存储类型
          path: ./uploads  # 上传文件路径
      data-agent:
        fusion-strategy: rrf  # 融合策略：rrf 或 weighted
        elasticsearch-min-score: 0.5  # Elasticsearch 最小分数
```

### 环境变量列表

| 变量名 | 说明 | 默认值 |
|-------|------|--------|
| `AI_DASHSCOPE_API_KEY` | DashScope API Key | 无（必需） |
| `DATA_AGENT_DATASOURCE_URL` | 业务数据库 URL | `jdbc:mysql://127.0.0.1:3307/data_agent...` |
| `DATA_AGENT_DATASOURCE_USERNAME` | 数据库用户名 | `root` |
| `DATA_AGENT_DATASOURCE_PASSWORD` | 数据库密码 | `root` |
| `OSS_ACCESS_KEY_ID` | OSS 访问密钥（可选） | 空 |
| `OSS_ACCESS_KEY_SECRET` | OSS 密钥（可选） | 空 |

## 🐛 常见问题

### 1. 后端启动失败：数据库连接错误

**错误信息**:
```
Communications link failure
```

**解决方案**:
- 检查 MySQL 是否启动
- 检查端口是否正确（默认 3307）
- 检查用户名密码是否正确
- 检查防火墙设置

### 2. 前端无法连接后端

**错误信息**:
```
Network Error
```

**解决方案**:
- 检查后端是否启动（访问 `http://localhost:8065/echo/ok`）
- 检查前端代理配置（`vite.config.js`）
- 检查 CORS 配置

### 3. DashScope API 调用失败

**错误信息**:
```
Invalid API Key
```

**解决方案**:
- 检查 API Key 是否正确
- 检查 API Key 是否有效（未过期）
- 检查账户余额是否充足
- 检查网络是否能访问阿里云服务

### 4. Schema 初始化失败

**错误信息**:
```
Failed to initialize schema
```

**解决方案**:
- 检查数据源连接是否正常
- 检查表是否存在
- 检查表是否有注释（建议添加表和字段注释）
- 查看后端日志获取详细错误信息

### 5. Python 代码执行失败

**错误信息**:
```
Python execution failed
```

**解决方案**:
- 开发环境：确保本地安装了 Python 3.8+
- 生产环境：使用 Docker 模式
- 检查 Python 依赖是否安装（pandas, matplotlib 等）
