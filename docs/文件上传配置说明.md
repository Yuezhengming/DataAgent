# 文件上传配置说明

## 问题：413 Request Entity Too Large

当上传文件时遇到 HTTP 413 错误，说明请求体过大，需要调整服务器的上传大小限制。

---

## ✅ 已完成的配置

### 1. Spring Boot 配置

**文件：** `spring-ai-alibaba-data-agent-management/src/main/resources/application.yml`

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 100MB      # 单个文件最大大小
      max-request-size: 100MB   # 整个请求最大大小
      enabled: true
```

**说明：**
- `max-file-size`: 单个上传文件的最大大小
- `max-request-size`: 整个 HTTP 请求的最大大小（包括文件和其他表单数据）
- 已设置为 **100MB**，与前端限制一致

---

## 🔧 可能需要的额外配置

### 2. Nginx 配置（如果使用）

如果你在 Spring Boot 前面使用了 Nginx 作为反向代理，需要在 Nginx 配置中添加：

**文件：** `/etc/nginx/nginx.conf` 或 `/etc/nginx/sites-available/your-site`

```nginx
http {
    # 设置客户端请求体最大大小为 100MB
    client_max_body_size 100M;
    
    server {
        listen 80;
        server_name your-domain.com;
        
        # 也可以在 server 块中单独设置
        client_max_body_size 100M;
        
        location /api/upload/ {
            # 或者只针对上传接口设置
            client_max_body_size 100M;
            
            proxy_pass http://localhost:8065;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            
            # 增加超时时间，避免大文件上传超时
            proxy_connect_timeout 600;
            proxy_send_timeout 600;
            proxy_read_timeout 600;
            send_timeout 600;
        }
        
        location / {
            proxy_pass http://localhost:8065;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        }
    }
}
```

**重启 Nginx：**
```bash
sudo nginx -t                    # 测试配置
sudo systemctl restart nginx     # 重启 Nginx
```

---

### 3. Apache 配置（如果使用）

**文件：** `/etc/httpd/conf/httpd.conf` 或 `.htaccess`

```apache
# 设置最大请求体大小为 100MB
LimitRequestBody 104857600

<VirtualHost *:80>
    ServerName your-domain.com
    
    # 针对上传路径设置
    <Location /api/upload/>
        LimitRequestBody 104857600
    </Location>
    
    ProxyPass / http://localhost:8065/
    ProxyPassReverse / http://localhost:8065/
    
    # 增加超时时间
    ProxyTimeout 600
</VirtualHost>
```

**重启 Apache：**
```bash
sudo apachectl configtest         # 测试配置
sudo systemctl restart httpd      # 重启 Apache
```

---

### 4. Tomcat 配置（如果使用）

**文件：** `conf/server.xml`

```xml
<Connector port="8080" protocol="HTTP/1.1"
           connectionTimeout="20000"
           redirectPort="8443"
           maxPostSize="104857600"
           maxSwallowSize="104857600" />
```

**说明：**
- `maxPostSize`: POST 请求最大大小（字节）
- `maxSwallowSize`: 最大吞吐量
- `104857600` = 100MB

---

### 5. Docker 配置（如果使用）

如果应用运行在 Docker 容器中，确保容器有足够的资源：

**docker-compose.yml:**
```yaml
version: '3'
services:
  data-agent:
    image: data-agent:latest
    ports:
      - "8065:8065"
    environment:
      - SPRING_SERVLET_MULTIPART_MAX_FILE_SIZE=100MB
      - SPRING_SERVLET_MULTIPART_MAX_REQUEST_SIZE=100MB
    volumes:
      - ./uploads:/app/uploads
    deploy:
      resources:
        limits:
          memory: 2G
        reservations:
          memory: 1G
```

## ⚠️ 注意事项

### 1. 内存考虑

上传大文件会占用服务器内存：
- **文件上传**：临时存储在内存或临时目录
- **文件解析**：OpenCSV/POI 会加载文件到内存
- **Pandas 分析**：数据加载到 Python 进程内存

**建议：**
- 服务器至少 4GB 内存
- 对于 100MB 文件，建议 8GB+ 内存
- 监控内存使用情况

### 2. 磁盘空间

确保上传目录有足够空间：

```bash
# 检查磁盘空间
df -h

# 检查上传目录
du -sh ./uploads
```

**配置上传目录：**
在 `application.yml` 中：
```yaml
spring:
  ai:
    alibaba:
      nl2sql:
        file:
          path: ./uploads  # 可以修改为其他路径
```

### 3. 超时设置

大文件上传可能需要更长时间，确保超时配置合理：

**application.yml:**
```yaml
server:
  tomcat:
    connection-timeout: 600000  # 10分钟
```

### 4. 安全考虑

- **文件类型验证**：已在代码中实现（只允许 .csv, .xlsx, .xls）
- **文件大小限制**：已配置 100MB
- **病毒扫描**：生产环境建议添加
- **访问控制**：建议添加用户认证

## 🔍 故障排查

### 问题 1: 仍然报 413 错误

**检查清单：**
1. ✅ Spring Boot 配置已修改
2. ⬜ 应用已重启
3. ⬜ 检查是否有 Nginx/Apache
4. ⬜ 检查浏览器控制台错误
5. ⬜ 检查服务器日志

**查看日志：**
```bash
# Spring Boot 日志
tail -f logs/spring.log

# Nginx 日志
tail -f /var/log/nginx/error.log
```

### 问题 2: 上传成功但解析失败

**可能原因：**
- 文件格式不正确
- 文件编码问题（CSV 需要 UTF-8）
- Excel 文件损坏
- 内存不足

**解决方法：**
- 检查文件格式
- 转换 CSV 编码为 UTF-8
- 增加 JVM 内存：`java -Xmx2g -jar app.jar`

### 问题 3: 上传很慢

**优化建议：**
- 使用 SSD 硬盘
- 增加网络带宽
- 考虑分块上传（未来功能）
- 压缩文件后上传
